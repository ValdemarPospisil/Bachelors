GoodAccess CLI klient pro Linux

GoodAccess CLI client for Linux
Anotace tématu
V současné době nabízí GoodAccess VPN řešení především prostřednictvím grafického uživatelského rozhraní, což nevyhovuje všem uživatelským scénářům. Zejména v prostředí serverů, automatizovaných systémů a DevOps pracovních postupů preferují administrátoři a pokročilí uživatelé řešení příkazové řádky pro snadnější automatizaci, skriptování a vzdálenou správu. Absence CLI aplikace pro Linux tak představuje značné omezení pro část zákaznické základny, která vyžaduje flexibilnější a lépe integrovatelné řešení.
Hlavním cílem této práce je navrhnout a implementovat funkční prototyp CLI aplikace pro správu GoodAccess VPN připojení na Linux distribucích (Debian, Fedora/RHEL) s využitím WireGuard protokolu.
Dílčí cíle práce zahrnují:
návrh a implementaci autentizačního mechanismu pro přihlášení uživatelů,
vytvoření architektury aplikace s důrazem na bezpečnost a modularitu,
implementaci bezpečného úložiště pro správu citlivých dat (secure storage),
realizaci funkcí pro správu VPN připojení (navazování, odpojování, monitoring stavu), 
návrh a implementaci systému aktualizací aplikace, 
vytvoření komplexní testovací sady pro ověření funkčnosti a bezpečnosti,
přípravu distribučních balíčků pro cílové Linux distribuce.
Výstupy práce budou zahrnovat:
CLI aplikaci s minimální funkcionalitou pokrývající autentizaci uživatele, navázání a odpojení VPN spojení, zobrazení stavu připojení a základní správu konfigurace,
integraci s WireGuard protokolem pro nastavení VPN tunelů,
implementaci secure storage mechanismu pro bezpečné uložení přihlašovacích údajů a klíčů,
distribuční balíčky pro Debian (.deb) a Fedora (.rpm) včetně instalačních skriptů,
automatizované testy pokrývající minimálně kritické funkce (autentizace, připojení, bezpečnost úložiště),
technickou dokumentaci popisující architekturu aplikace, API rozhraní a návod pro vývojáře.
